# Contributing

Thanks for your interest in these projects! They are primarily personal
portfolio work, but suggestions, bug reports, and pull requests are welcome.

## How to contribute

1. **Bugs & ideas** — open an issue using the provided templates.
2. **Pull requests** — fork the repo, create a feature branch, and open a PR
   against `main`. Keep changes focused and describe the motivation.

## Conventions

- Match the existing code style of the repository.
- Keep commits small and messages descriptive.
- Run the project's own lint/build steps before opening a PR.

## Security

Do not report security vulnerabilities in public issues — see [SECURITY.md](SECURITY.md).
