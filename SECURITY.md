# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my repositories, please
report it privately rather than opening a public issue.

- Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  on the affected repository (Security → Report a vulnerability), **or**
- Contact [@IamSRC12](https://github.com/IamSRC12) directly.

Please include a description, reproduction steps, and any relevant details.
You can expect an acknowledgement within a few days.

## Supported Versions

These projects are maintained on their default branch; fixes are applied to the
latest version.
